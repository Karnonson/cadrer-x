# Site du studio

Le site d'Atelier Nord, un studio de design web de deux personnes à Lyon. Pages : accueil, nos
réalisations, et un formulaire de contact qui envoie un email à la boîte du studio (par notre compte
SMTP Brevo).

Lancer : `pnpm install`, puis `pnpm dev`. Vérifs : `pnpm lint`, `pnpm typecheck`, `pnpm test`.
