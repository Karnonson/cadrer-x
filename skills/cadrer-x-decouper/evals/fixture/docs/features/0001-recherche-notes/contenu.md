# Recherche dans les notes — contenu

## SC1 Recherche

- Titre : Chercher dans mes notes
- Champ : Un mot de ta note
- Bouton : Chercher

### avant

- Message : Tape un mot dont tu te souviens. On cherche dans toutes tes notes.

### resultats

- Compte : 1 note contient « {mot} » · {n} notes contiennent « {mot} »
- Carte : le livre, la page si tu l'as notée, les mots autour, la date

### aucun

- Message : Aucune note ne contient « {mot} ». Essaie un autre mot.

### erreur

- Message : La recherche n'a pas pu se faire. Réessaie dans un instant.

## SC2 Note

- Retour : ← Retour aux résultats
- Méta : Page {page} · {date}
