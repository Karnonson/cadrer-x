# Recherche dans les notes — décisions
## Décisions
- D1 La recherche ne regarde que les notes du membre — pourquoi : les notes sont privées (M1)
- D2 Les accents et les majuscules ne comptent pas (« ete » trouve « Été ») — pourquoi : les membres tapent vite sur un téléphone
- D3 Les résultats montrent la note la plus récente d'abord — pourquoi : supposé
